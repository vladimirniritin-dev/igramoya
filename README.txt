ЛЕТНИЕ ИСТОРИИ — версия 1.2.9
Windows 10/11 · исходники Electron

ЗАПУСК ИГРЫ
1. Распакуйте весь архив в отдельную папку.
2. Установите Node.js LTS с https://nodejs.org/, если он ещё не установлен.
3. Запустите LAUNCH_GAME.bat.
4. При первом запуске скрипт установит зависимости через npm (нужен интернет).

СБОРКА УСТАНОВЩИКА EXE
1. Установите Node.js LTS.
2. Запустите BUILD_WINDOWS_INSTALLER.bat.
3. Готовый установщик появится в папке dist.

УПРАВЛЕНИЕ
F11 — включить/выключить полный экран.
Esc — выйти из полного экрана.
Размер окна и качество графики настраиваются в разделе «Настройки».

СОХРАНЕНИЯ
Сохранения хранятся в локальном хранилище профиля Electron. Не удаляйте папку профиля приложения, если хотите сохранить прогресс.
В версии 1.2.9 повреждённый список сохранений больше не перезаписывается автоматически: исходные данные резервируются, а восстановление читаемых слотов запускается из раздела «Сохранения».

ПРИМЕЧАНИЕ
Архив содержит исходники и ресурсы игры. Установщик Windows не включён: его нужно собрать на Windows указанным скриптом.
